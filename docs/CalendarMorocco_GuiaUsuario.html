1. Instalación y arranque

Repositorios necesarios

Calendar Morocco se compone de dos repositorios independientes que debes descargar en local, ambos en la rama develop:

  • CalendarGenerateBack — el servicio que calcula los calendarios.
  • CalendarGenerateFront — la aplicación web desde la que trabajas.
git clone git@github.com:ES-MEV-APPLICATIONS/CalendarGenerateBack.git
git clone git@github.com:ES-MEV-APPLICATIONS/CalendarGenerateFront.git

git -C CalendarGenerateBack switch develop
git -C CalendarGenerateFront switch develop

Requisitos previos

NecesitasPara qué sirve
Acceso a GitHubDescargar los dos repositorios.
Java 21Ejecutar el servicio de generación.
Maven (incluido como mvnw)Compilar y arrancar el servicio.
Node.js + pnpm 10.29.3Arrancar la aplicación web.
💡 Consejo Antes de empezar, comprueba las versiones instaladas: java -version y pnpm --version. Si pnpm --version ya devuelve 10.29.3, no necesitas instalar nada más para trabajar con el proyecto.

Arrancar el servicio (puerto 8080)

cd CalendarGenerateBack
sh mvnw spring-boot:run

Cuando el servicio haya arrancado, comprueba que responde abriendo en el navegador:

http://localhost:8080/actuator/health

Arrancar la aplicación web (puerto 4200)

cd CalendarGenerateFront
pnpm install
pnpm start

Cuando aparezca Local: http://localhost:4200/ en la terminal, abre esa dirección en el navegador.

⚠️ Si la aplicación web no carga datos Comprueba primero que el servicio del punto anterior (puerto 8080) está arrancado y responde correctamente. Si el servicio no está disponible, la aplicación web no podrá mostrar competiciones ni generar calendarios.

Alternativa: arrancar desde Visual Studio Code

1
Abre CalendarGenerateBack en Visual Studio Code y pulsa F5 (configuración de depuración incluida en el repositorio).
2
Abre CalendarGenerateFront en una segunda ventana y ejecuta pnpm install (la primera vez) y después pnpm start en su terminal integrada.
3
Abre http://localhost:4200 en el navegador.

Actualizar los repositorios

Cuando ya tengas ambos repositorios descargados y quieras trabajar con la última versión de develop:

git -C CalendarGenerateBack pull --ff-only origin develop
git -C CalendarGenerateFront pull --ff-only origin develop

2.1 Excel Manager

Propósito. Pantalla para consultar, subir, descargar y borrar los ficheros Excel de entrada de una competición y temporada, antes de generar horarios.

Cómo llegar. Menú principal → Excel Manager.

Campos y botones

Campo / botónQué hace
CompetitionSelecciona la competición.
RefreshActualiza la lista de competiciones y temporadas disponibles.
SeasonSelecciona la temporada.
Lista "Available Excel Files"Muestra los ficheros ya subidos para esa competición/temporada, con tamaño y fecha.
Download (por fichero)Descarga ese Excel para revisarlo.
Delete (por fichero)Elimina ese fichero. Solo hazlo si estás seguro de que ya no se necesita.
Botón "i" junto a "Upload Excel File"Muestra el formato de nombre esperado para el fichero.
Selector de fichero (.xlsx)Elige el nuevo Excel a subir.
UploadSube el fichero seleccionado.
Download Initial ExcelDescarga la plantilla inicial de la liga, cuando todavía no se ha subido ningún Excel propio para esa competición/temporada.

Qué puede hacer el usuario

1
Selecciona Competition y Season.
2
Pulsa Refresh y revisa los ficheros ya disponibles.
3
Si es la primera vez, descarga el Excel inicial con Download Initial Excel y utilízalo como base.
4
Prepara la nueva versión del fichero (siguiente apartado) y selecciónala con el campo de subida.
5
Pulsa Upload.
6
Comprueba que aparece en la lista de ficheros disponibles.

Convención de nombre del fichero

La aplicación valida el nombre del fichero antes de aceptarlo. El mensaje real que muestra cuando el nombre no es válido es:

⚠️ Mensaje real de la aplicación "Use this pattern (case-insensitive): CalendarD1-v<number>.xlsx". Ejemplos: CalendarD1-v0.xlsx, CalendarD2-v5.xlsx.

En la práctica, trabaja siempre incrementando la versión sobre el último Excel válido: Initial → V0 → V1 → V2…. No sobrescribas inmediatamente la última versión validada; conserva el fichero anterior hasta validar el nuevo.

Competiciones externas y aplazamientos

El Excel puede contener información relacionada con competiciones externas (por ejemplo, participación en torneos continentales) que obligan a mover un partido de liga a otra fecha. Esa información no debe eliminarse solo porque no sea una fila "normal" de la competición: puede condicionar qué fechas están disponibles para el cálculo de horarios.

Dependencia entre Primera y Segunda División

Los horarios de Segunda División deben prepararse después de haber generado y validado las mismas jornadas de Primera División (D1 antes que D2, F1 antes que F2), incorporando en el Excel de Segunda la información ya consolidada de Primera.

2.2 Generate Calendar

Propósito. Pantalla desde la que se ejecuta el cálculo de horarios de las jornadas, a partir del Excel ya subido en Excel Manager.

Cómo llegar. Menú principal → Generate Calendar (pantalla de inicio de la aplicación).

Campos y botones

Campo / botónQué hace
CompetitionCompetición que quieres generar.
RefreshRefresca competiciones y temporadas disponibles.
SeasonTemporada de trabajo.
Excel File From StorageExcel ya subido en Excel Manager para esa competición y temporada.
Last Round To AssignÚltima jornada que debe quedar procesada (entero mayor que 0).
Generate CalendarInicia el cálculo de horarios.
Generation LogsPanel con el detalle de la ejecución.
Refresh LogsActualiza los logs mostrados.

Qué significa exactamente "Last Round To Assign"

Es la última jornada que debe quedar procesada, no cuántas jornadas nuevas quieres generar. Ejemplo: si el Excel seleccionado contiene información de las jornadas 1 a 5, selecciona ese fichero e introduce 5.

Validaciones reales de la pantalla

⚠️ Mensajes reales de la aplicación Si falta competición, temporada o Excel: "Please select competition, season and Excel file."
Si Last Round To Assign no es un entero mayor que 0: "Please set a valid Last Round To Assign (> 0)."

Qué puede hacer el usuario

1
Selecciona Competition.
2
Selecciona Season.
3
Selecciona el Excel correcto en Excel File From Storage.
4
Introduce Last Round To Assign.
5
Pulsa Generate Calendar.
6
Espera a que termine la ejecución y descarga el Excel resultante.
7
Revisa Generation Logs (y su Generation ID) si necesitas comprobar el detalle de la ejecución.
8
Si es Primera División, valida el resultado antes de preparar el Excel de Segunda División.
💡 Consejo Para la siguiente solicitud, parte siempre del resultado ya validado, conserva los horarios generados, añade los nuevos partidos/jornadas y guarda la siguiente versión antes de volver a generar.

3. Creación del calendario inicial para el sorteo

ℹ️ Importante Este paso no sustituye a la generación de horarios de las jornadas. Primero se define quién juega contra quién en cada jornada (este apartado); después se calculan fechas y horas desde la aplicación web (Bloque 2).

Este proceso se usa al principio de la temporada, cuando todavía no existe un calendario base para una competición. Es distinto del uso diario descrito en el Bloque 2 y no está disponible desde la aplicación web: lo ejecuta el equipo técnico desde el propio repositorio del servicio.

Qué genera

Genera varias propuestas de emparejamientos por jornada (quién juega contra quién), no una única propuesta. Entre esas propuestas se elige después la definitiva mediante sorteo.

Antes de empezar

  • Temporada y competición confirmadas.
  • Lista definitiva de equipos, con ascensos y descensos ya incorporados.
  • Restricciones iniciales revisadas (por ejemplo, equipos que no deben coincidir en casa el mismo día).

Cómo se obtienen las propuestas

Se ejecuta la herramienta generadora de propuestas de sorteo, que crea las combinaciones válidas de emparejamientos según las restricciones configuradas para la temporada.

ℹ️ Dato verificado en el código El número de propuestas generadas depende de la configuración de la temporada. En la configuración actual del repositorio, ese valor está fijado a 1.000 propuestas; confírmalo con el equipo antes de dar por bueno este número para una temporada nueva.

Cómo se obtiene el Excel para el sorteo

A continuación se exportan esas propuestas a un fichero Excel, usando la plantilla de la competición correspondiente. Ese Excel es el que se utiliza durante el sorteo para elegir la propuesta definitiva.

Después del sorteo

1
Conserva el Excel de la propuesta elegida como calendario base de la temporada para esa competición.
2
Prepara la versión de entrada correspondiente (Excel Initial/V0).
3
Súbela mediante Excel Manager.
4
Continúa con el flujo del Bloque 2 (Excel Manager → Generate Calendar → Generated Results) para calcular los horarios de las jornadas.
⚠️ No confundir Ejecutar este apartado no calcula fechas ni horas de partidos. Solo obtiene el calendario base (emparejamientos). El cálculo de horarios se hace siempre después, desde la aplicación web.
